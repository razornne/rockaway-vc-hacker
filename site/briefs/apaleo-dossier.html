Risks and caveats

  • Analyst viewDependency on third‑party LLM vendors: Apaleo lists Anthropic and OpenAI as subprocessors for AI features, creating operational and compliance risk.[10, 11]
  • Analyst viewUnverified compliance claims: website asserts SOC 2/PCI/PSD2/GDPR compliance but collected security pages provide no public attestations or trust portal.[37, 12]
  • Analyst viewSandbox/third‑party outages: status page shows distribution/sandbox failures tied to third‑party services, signalling fragile developer experience or integration dependency.[38, 39]

Questions for founders

  • Please provide the latest SOC 2/PCI/PSD2 attestations and penetration test reports referenced on the site (claim: SOC2/PCI/PSD2).[37, 12]
  • Describe data flows, prompt logging, retention and redaction for Anthropic and OpenAI LLM calls and whether customers can opt out of vendor processing.[10, 11, 40]
  • Supply three reference customers (contracts or contacts) that substantiate the claimed 1,700 properties / 85,000 units and allow inspection of integration depth.[6]
  • Provide architecture/design docs for MCP Server, details on authentication, authorization, audit logs and example agent interactions.[8, 29]
